NIOLA CLOTHES WEBSITE

FILES
- index.html: website structure and content
- style.css: layout, colors, responsive/mobile styling
- script.js: mobile navigation and current year
- images/: uploaded fashion and clothing reference images

HOW TO OPEN
1. Extract niola_clothes_website.zip.
2. Open the folder.
3. Double-click index.html. It should open in your browser.
4. To edit the website, open the folder in Visual Studio Code and edit index.html, style.css, or script.js.
